Know when your network drops. Know how long it lasts. Keep the evidence.

Synups is a local-first Avalonia network reliability monitor migrated from Bill Menees' WirePeep. It records confirmed ICMP incidents, observed recoveries, comments and durable local evidence. ICMP reachability to configured peers is not proof of whole-Internet availability.

## Installation and limits

- **Windows:** run `Synups.exe`; unsigned, no installer. SmartScreen/organization policy may block it.
- **macOS:** open `Synups.app`; ad-hoc integrity only, **not Developer ID signed/notarized; Gatekeeper rejects trusted delivery**. Do not disable OS security. Follow the included INSTALLATION.md and organizational policy.
- **Linux:** run `./Synups`; preserve executable permissions and install documented desktop libraries. Native GUI evidence is Ubuntu24.04/X11 with Xvfb/Openbox; Wayland/other desktops are not universally certified.

Programmatic native controls are not physical tray/keyboard/Save-panel acceptance or OS notification delivery. Actual next-login execution, alert sounds/taskbar equivalents, genuine legacy import and broader topology/suspend/accessibility checks remain incomplete. Known permission and storage limitations are documented. Newer source changes, if any, do not become part of these frozen binaries.

Public0.1.0 remains an unchanged rollback release. No competition form submission or accepted entry is implied by a release.
